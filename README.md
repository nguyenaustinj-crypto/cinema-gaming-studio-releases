# Cinema Gaming Studio: releases

Each release here is one version of Cinema Gaming Studio, with two files:

- `CinemaGamingStudio.exe`: the app.
- `update.json`: what the app reads at start to tell you a new version is out (version, download link,
  SHA-256 of the exe, Skyrim mod list version).

You don't need to come here: the app shows a banner when a new version is out, downloads it, checks it and
restarts into it when you press Restart. If you'd rather get it by hand, download `CinemaGamingStudio.exe` from
the newest release.

The source code isn't here; this repo only holds the release files.
